# 세계 관광 명소 탐색 및 여행 경로 최적화 시스템

## 1. 프로젝트 소개

해외여행을 계획할 때 관광지 정보, 날씨, 이동 경로 등을 여러 사이트에서 개별적으로 검색해야 하는 불편함이 있다. 또한 여러 관광지를 방문할 경우 효율적인 방문 순서를 직접 결정하기 어렵다는 문제점이 있다.

본 프로젝트는 이러한 문제를 해결하기 위해 세계 주요 관광지의 정보를 제공하고, 실제 이동 경로를 바탕으로 효율적인 방문 순서와 여행 일정을 설계하는 프로그램이다.

Python과 Streamlit을 기반으로 개발하였으며, 외부 API를 통해 관광지 사진, 소개, 날씨, 이동거리 및 예상 소요 시간 등의 정보를 제공한다. 특히 순열을 활용한 완전탐색 알고리즘을 적용하여 사용자가 선택한 관광지의 최적 방문 순서를 계산한다.

## 2. 사용법

### 관광지 탐색

1. 방문하고 싶은 국가와 도시를 선택한다.
2. 해당 도시의 주요 관광지 중 원하는 관광지를 선택한다.
3. 관광지의 사진, 한국어 소개 및 지도상의 위치를 확인한다.
4. 현재 날씨와 3일간의 날씨 예보를 확인한다.
5. 원하는 날짜를 선택하여 날씨에 따른 여행 적합도와 추천 정보를 확인한다.

### 여행 경로 탐색

1. 사이드바에서 여행 경로 탐색 페이지로 이동한다.
2. 여행할 국가와 도시를 선택한다.
3. 방문하고 싶은 관광지와 출발지를 선택한다.
4. 이동 수단을 도보 또는 자동차로 설정한다.
5. 최적 경로를 계산하여 지도에 표시된 방문 순서를 확인한다.
6. 기존 경로와 최적 경로의 이동거리 및 예상 소요 시간을 비교한다.
7. 자동으로 생성된 여행 일정표를 확인하고 필요한 경우 CSV 파일로 저장한다.

## 3. 주요 기능 설명

### 3-1. 국가별 관광지 정보 제공

- 대한민국, 일본, 중국, 미국, 프랑스, 호주의 주요 관광지 정보 제공
- 국가 및 도시별 관광지 선택
- 위키백과 API를 활용한 관광지 사진 및 한국어 소개 제공
- 위도와 경도 데이터를 활용한 관광지 위치 표시

### 3-2. 날씨 정보 제공

- Open-Meteo API를 활용한 최신 날씨 정보 조회
- 현재 기온, 체감 기온, 습도, 풍속 제공
- 3일간의 최고·최저기온 및 강수확률 제공
- 날씨 조건에 따른 여행 준비 안내

### 3-3. 날씨 기반 여행 적합도 분석

관광지를 실내 중심, 야외 중심, 실내·야외 혼합형으로 분류하고 기상 조건에 따라 여행 적합도를 계산한다.

- 초기 적합도를 100점으로 설정
- 강수확률, 기온, 풍속에 따라 점수 차감
- 관광지 유형에 따라 기상 조건의 영향 차등 적용
- 최종 점수를 0~100점 범위로 표시
- 날씨가 좋지 않을 경우 같은 도시의 실내 중심 관광지 추천

여행 적합도는 직접 설계한 조건과 기준에 따라 계산한 참고용 지표이다.

### 3-4. 실제 이동 경로 기반 최적 경로 탐색

기존 직선거리 계산 방식의 한계를 보완하기 위해 Geoapify API를 활용한다. 실제 도로와 보행로를 기반으로 관광지 사이의 이동거리와 예상 소요 시간을 계산한다.

순열을 활용한 완전탐색 알고리즘으로 가능한 모든 방문 순서를 비교하고, 총 예상 이동시간이 가장 짧은 방문 순서를 선택한다.

- 도보 및 자동차 이동 수단 선택
- 관광지 사이의 이동거리와 예상 소요 시간 계산
- 순열을 활용한 최적 방문 순서 탐색
- 지도에 실제 이동 경로 및 방문 순서 표시

### 3-5. 경로 비교 및 분석

- 기존 방문 순서와 최적 방문 순서 비교
- 총 이동거리 및 예상 소요 시간 비교
- 경로 최적화에 따른 이동 효율 분석

### 3-6. 자동 여행 일정표 생성

- 최적 방문 순서를 바탕으로 여행 일정표 생성
- 관광지별 이동시간과 체류시간 반영
- 예상 도착 및 출발 시각 계산
- 여행 일정표 CSV 파일 다운로드

## 4. 실행 방법

### 웹사이트에서 실행

별도의 프로그램 설치 없이 아래 웹사이트에 접속하여 이용할 수 있다.

https://minamina.streamlit.app/

### 로컬 환경에서 실행

**1. 프로젝트 파일 다운로드**

GitHub 저장소에서 프로젝트 파일을 다운로드한다.

**2. 필요한 라이브러리 설치**

터미널에서 다음 명령어를 실행한다.

```bash
pip install -r requirements.txt
```

**3. API 키 설정**

Geoapify에서 API 키를 발급받은 후 프로젝트 폴더에 `.streamlit/secrets.toml` 파일을 생성하고 다음과 같이 입력한다.

```toml
GEOAPIFY_API_KEY = "발급받은 API 키"
```

API 키가 외부에 노출되지 않도록 해당 파일은 GitHub에 업로드하지 않는다. Streamlit Community Cloud에서 실행하는 경우에는 앱의 Secrets 설정에 API 키를 등록한다.

**4. 프로그램 실행**

터미널에서 다음 명령어를 실행한다.

```bash
streamlit run main.py
```

실행 후 브라우저에서 프로그램을 이용할 수 있다.

## 6. 프로젝트의 한계 및 개선 방향

외부 API의 응답 상태와 제공 데이터에 따라 일부 관광지 정보나 이동 경로가 제한될 수 있다. 또한 예상 이동시간은 실제 교통 상황과 차이가 발생할 수 있으며, 관광지 운영시간이나 휴관일은 별도로 확인해야 한다.

향후 관광지 운영시간, 최신 환율 및 여행 경비 계산 등의 정보를 추가하여 더욱 실용적인 여행 계획 프로그램으로 발전시키고자 한다.
